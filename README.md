## Источник истины
Здесь хранятся только стратегия, методология и метрики. Тексты и публичные кейсы — в Murat House; диагностика и интервью — в Business Discovery; технические доказательства и gates — в MPE; данные по заявкам — в существующей Minibase при наличии подходящих структур.

**Без клиентских персональных данных, API-ключей, внутренних договоров и секретов.**

## Принцип развития
Один объект → одна идентичность → много представлений. Не создавать параллельную CRM, CMS, граф, оркестратор или новый механизм интервью.
