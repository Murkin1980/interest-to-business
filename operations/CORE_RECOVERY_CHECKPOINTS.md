## Invariant: why this project exists
Find a repeatable, evidence-led way to turn a person's **interest and experience** into a genuine problem hypothesis, test whether others have that problem, offer a proportionate solution, measure value created and only then decide whether there is a business.

The real value is not a collection of AI tools, articles, regional sites or arbitrary business ideas. It is a tested decision method, including evidence for **stopping** weak ideas.

### Minimal portable chain
Interest/skills → observed unmet need → specific audience and their existing behaviour → costly/frustrating problem → solution alternatives → cheapest safe falsifiable test → outcome/cost → STOP / ITERATE / SCALE → reusable pattern (with counterexamples).

### Workstreams
A: expertise/services; B: experience-derived tools/templates; C: engineering experiments. These are monetization *routes*, not three separate cores. No forced Murat House publishing: ITB can later have a distinct website. Country/language are context, not duplicated core logic.
